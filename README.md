# WPS-Paraphrasing

WPS-Paraphrasing 是一个 WPS 文字（Writer）插件，帮助用户在英文写作中快速完成**同义替换**：选中一个词语，即可获得五个贴近上下文语境、表达地道的英文同义或近义候选词，一键替换，让措辞更丰富、更专业。

## 功能亮点

- **上下文感知推荐**：不仅给出同义词，还会结合选词所在句子的语境进行筛选与排序，优先推荐符合当前语境、语域（正式/中性/口语）和搭配习惯的词。
- **地道用语**：候选词来自高质量词库与语言模型判断，避免生硬、过时或不常见的替换。
- **一键替换**：点击候选词即可完成替换，自动保持原文的大小写形式（如首字母大写、全大写）。
- **快捷高效**：选中词语后通过面板或快捷操作唤起，无需离开当前文档。

## 使用流程

1. 在 WPS 中打开一篇英文文档。
2. 选中一个英文单词或短语。
3. 打开插件面板（或点击悬浮提示），查看五个同义/近义候选词。
4. 鼠标悬停可查看每个候选词的简要释义与语境说明。
5. 点击候选词完成替换。

## 技术方案（规划中）

- **前端**：WPS 加载项（HTML/JS，基于 WPS JS 加载项框架），负责选词交互、候选词面板与替换逻辑。
- **后端**：语言服务接口，接收选词与上下文句子，返回语境化排序的同义候选词及释义。
- **数据**：同义词库（如 WordNet / Open English WordNet）+ 上下文语义模型，用于候选词生成与语境匹配打分。
